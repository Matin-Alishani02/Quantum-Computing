# نتیجهٔ آزمون بستهٔ تحویلی

تاریخ بررسی: ۲۰۲۶-۱۰-۱۴

| مورد | نتیجه |
|---|---|
| محیط آزمون | Python 3.12.14، Linux x86_64 |
| وابستگی‌های اصلی | NumPy 2.3.5 و Qiskit 2.5.0 |
| اجرای مستقل فصل‌ها | ۲۶ از ۲۶ فصل موفق |
| آزمون‌های خودکار | ۳۲ آزمون موفق |
| مثال‌های پایتون | ۲۵۴ مثال |
| زمان مجموع اجرای فصل‌ها در این محیط | 13.73 ثانیه |

این نتیجه متعلق به همین محیط است؛ سرعت اجرا و شمارش دقیق نمونه‌های تصادفی در سیستم دیگر می‌تواند فرق کند. اجرای مستقیم فایل‌های فصل، آزمون‌های حالت و مدار و گزارش‌گیری از اجراکننده بررسی شده‌اند. نصب و اجرای بومی Windows و macOS در این محیط آزمایش نشده است؛ راهنمای آن‌ها در README آمده است.

جزئیات ماشین‌خوانِ زمان و وضعیت هر فصل در validation_summary.json قرار دارد. هشدار کارایی ماتریس پراکنده در فصل ۲۳، شکست آزمون نیست.

## آزمون‌های علمی مشخص

- وفاداری انتقال کوانتومی ایدئال برابر یک؛
- هم‌ارزی QFT دستی و QFTGate؛
- احتمال موفقیت گروور برای سه کیوبیت و دو تکرار؛
- پاسخ ناصفر دستگاه تهی سایمون و بازیابی رشتهٔ پنهان نمونه؛
- کامل‌بودن مجموعهٔ کراوس کانال واپاشی دامنه؛
- رعایت کران مسیر بحرانی با افزایش تعداد کارخانه‌ها.

این آزمون‌ها ویژگی‌های مشخصی را کنترل می‌کنند و پوشش اثباتی تمام ادعاهای نظری کتاب نیستند.
