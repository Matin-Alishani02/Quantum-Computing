# کدهای همراه کتاب رایانش کوانتومی

این مخزن شامل **۲۵۴ مثال پایتون در ۲۶ فصل** است که از آخرین نسخهٔ اصلاح‌شدهٔ کتاب استخراج و برای اجرای مستقل هر فصل مرتب شده‌اند. دو بلوک مربوط به نصب محیط، در دستورهای راه‌اندازی زیر پوشش داده شده‌اند.

هر فصل یک فایل `lab.py` و یک راهنمای فارسی دارد. مثال‌های داخل فصل با شماره و عنوان بخش کتاب مشخص شده‌اند و به‌ترتیب اجرا می‌شوند. وابستگی‌های میان مثال‌های همان فصل حفظ شده است؛ اجرای فصل‌های قبلی لازم نیست.

## راه‌اندازی سریع در ویندوز

**Python 3.12 نسخهٔ ۶۴ بیتی** پیشنهاد می‌شود. بسته برای Python 3.11 به بالا تنظیم شده و محیط آزمون تحویل در `docs/VALIDATION.md` ثبت شده است.

ZIP را استخراج کنید، در پوشهٔ اصلی پروژه CMD یا PowerShell باز کنید و دستورها را جداگانه اجرا کنید:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe run.py --chapter 1
```

اگر دستور `py` در دسترس نیست، پس از اطمینان از نسخهٔ پایتون، دستور اول را با `python -m venv .venv` جایگزین کنید. استفادهٔ مستقیم از پایتون محیط مجازی به فعال‌سازی محیط یا تغییر Execution Policy پاورشل نیاز ندارد.

## راه‌اندازی در Linux و macOS

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python run.py --chapter 1
```

در ادامه، `python` به پایتون همین محیط مجازی اشاره دارد؛ می‌توانید همچنان مسیر کامل آن را مانند دستورهای بالا بنویسید.

## اجرا و آزمون پیش از انتشار

دیدن فهرست فصل‌ها:

```bash
python run.py --list
```

اجرای یک یا چند فصل:

```bash
python run.py --chapter 14
python run.py --chapter 9 11 15 16
```

اجرای تمام فصل‌ها و ذخیرهٔ گزارش:

```bash
python run.py --all --quiet
```

گزینهٔ `--quiet` فقط خروجی طولانی مثال‌ها را از کنسول حذف می‌کند. شروع و پایان هر فصل، زمان اجرا و وضعیت آن همچنان نمایش داده می‌شود و خروجی کامل در فایل لاگ باقی می‌ماند.

اجرای آزمون‌ها:

```bash
python -m unittest discover -s tests -v
```

آزمون‌ها علاوه بر اجرای همهٔ فصل‌ها، وفاداری انتقال کوانتومی، هم‌ارزی QFT دستی با کتابخانه، احتمال گروور، دستگاه خطی سایمون، کامل‌بودن عملگرهای کانال و کران مسیر بحرانی زمان اجرا را بررسی می‌کنند.

پس از پایان، باید تمام فصل‌ها `PASSED` و نتیجهٔ آزمون‌ها `OK` باشد. در پوشهٔ `outputs` این فایل‌ها ساخته می‌شوند:

- `ch01.log` تا `ch26.log`: خروجی کامل هر فصل؛
- `summary.json`: وضعیت، نسخهٔ پایتون و وابستگی‌ها، زمان‌ها و مسیر لاگ‌ها؛
- `summary.csv`: خلاصهٔ قابل بازکردن در Excel.

هر فصل در یک فرایند جدا اجرا می‌شود. سقف پیش‌فرض زمان هر فصل ۳۰۰ ثانیه است؛ در سیستم کندتر می‌توانید آن را بیشتر کنید:

```bash
python run.py --all --quiet --timeout 900
```

اجرای مستقیم فایل یک فصل نیز ممکن است:

```bash
python chapters/ch15_grover_search/lab.py
```

## ساختار فایل‌ها

| مسیر | کاربرد |
|---|---|
| `chapters/chXX_.../lab.py` | مثال‌های اجرایی همان فصل، با عنوان و شمارهٔ بخش |
| `chapters/chXX_.../README.md` | فهرست مثال‌ها و فرمان اجرای فصل |
| `run.py` | اجرای فصل‌های منتخب یا همهٔ فصل‌ها با لاگ و گزارش |
| `tests/test_labs.py` | آزمون اجرای فصل‌ها و چند خاصیت فیزیکی و محاسباتی |
| `requirements.txt` | وابستگی‌های مستقیم با نسخهٔ مشخص |
| `requirements-lock.txt` | نسخهٔ وابستگی‌های مستقیم و غیرمستقیم محیط آزمون |
| `manifest.json` | نگاشت فصل‌ها و مثال‌ها به فایل و خطوط کد، همراه با شناسهٔ محتوایی نسخهٔ مبنا |
| `docs/VALIDATION.md` | نتیجه و محدودیت‌های آزمون بستهٔ تحویلی |
| `.github/workflows/tests.yml` | اجرای خودکار آزمون‌ها در GitHub Actions با Python 3.12 |

## نکته‌های تفسیر خروجی

- این مثال‌ها برای شبیه‌ساز محلی و محاسبات آموزشی کوچک‌اند؛ حساب IBM، کلید API، GPU یا پردازندهٔ کوانتومی لازم ندارند.
- نصب اولیه به اینترنت نیاز دارد؛ اجرای مثال‌ها پس از نصب، به دریافت داده یا سرویس ابری وابسته نیست.
- در Qiskit، کلید رشته‌ای نتایج معمولاً کیوبیت با اندیس بزرگ‌تر را سمت چپ نشان می‌دهد. توضیح قرارداد ترتیب بیت‌ها را در هر مثال رعایت کنید.
- نمونه‌گیری تصادفی ممکن است با تغییر نسخه یا محیط، اندکی تغییر کند. برای نتایج احتمالاتی انتظار برابری دقیق تمام شمارش‌ها را نداشته باشید.
- پیام `SparseEfficiencyWarning` در نمونهٔ شبیه‌سازی، هشدار کارایی تبدیل ماتریس است؛ شکست اجرا با وضعیت `FAILED` و کد خروج غیرصفر مشخص می‌شود.
- مدل‌های منابع سخت‌افزار، هزینه، نویز و مقایسهٔ فناوری‌ها در برخی فصل‌ها آموزشی‌اند و خروجی آن‌ها معیار عملکرد یک دستگاه واقعی نیست.

## رفع خطاهای معمول

**`ModuleNotFoundError`**: نصب و اجرا را با همان پایتون محیط مجازی انجام دهید. در ویندوز از `.venv\Scripts\python.exe` استفاده کنید.

**خطا هنگام نصب نسخهٔ مشخص**: ابتدا نسخهٔ پایتون و ۶۴ بیتی بودن آن را بررسی و pip را به‌روز کنید. به‌جای تغییر هم‌زمان نسخه‌های بسته‌ها، خروجی کامل خطای نصب را نگه دارید.

**نمایش نامرتب فارسی یا کاراکترهای مدار در ترمینال**: فایل‌های لاگ UTF-8 هستند. آن‌ها را در VS Code یا ویرایشگری با پشتیبانی UTF-8 باز کنید؛ اجراکننده نیز UTF-8 را برای فرایند فصل‌ها تنظیم می‌کند.

**نام متغیر تعریف نشده هنگام کپی یک تکهٔ کد**: بعضی مثال‌ها از تابع‌ها و متغیرهای مثال‌های قبلی همان فصل استفاده می‌کنند. فایل کامل `lab.py` فصل را اجرا کنید.

## انتقال به ریپوی خودتان

پس از اجرای موفق آزمون‌ها، محتوای همین پوشه را در ریشهٔ ریپوی خود قرار دهید. پوشهٔ `.venv`، خروجی اجراها و کش پایتون را منتشر نکنید؛ این مسیرها در `.gitignore` قرار دارند. فایل Word یا PDF کتاب داخل این بسته نیست. این ZIP به ریپوی شما متصل نمی‌شود و چیزی را خودکار منتشر نمی‌کند.
