# فصل 1: رایانش کوانتومی چیست؟

از ریشهٔ پروژه اجرا کنید:

~~~bash
python run.py --chapter 1
~~~

اجرای مستقیم این فصل نیز ممکن است:

~~~bash
python chapters/ch01_introduction/lab.py
~~~

مثال‌ها به‌ترتیب کتاب در همین فایل آمده‌اند و متغیرها و تابع‌های مثال‌های قبلی را استفاده می‌کنند. برای اجرای یک فصل نیازی به اجرای فصل قبل نیست.

| مثال | بخش کتاب | موضوع |
|---:|---|---|
| 1 | ۷. آزمایشگاه Python و Qiskit | ۷-۲. آزمایش اول: ساخت هادامارد فقط با NumPy |
| 2 | ۷. آزمایشگاه Python و Qiskit | ۷-۳. آزمایش دوم: یک کیوبیت با Qiskit |
| 3 | ۷. آزمایشگاه Python و Qiskit | ۷-۴. آزمایش سوم: ساخت یک جفت بل |
